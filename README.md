# FTMap_results_analysis
Helper scripts to analyze FTMap results for COVIB analysis
# Script description
Required python packages:
-  NumPy
-  Scikit-learn
-  RDkit
-  Biopython

FTMap_PDB_dist_calc.py - This script calculates the center of mass of each FTMap probe clusters, then calculates the distances compared to a reference input.

FTMap_sdf_clustering.py - This script groups FTMap clusters into a single group (cluster) based on proximity.
